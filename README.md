# Skills_Coral

Skills duráveis da CoralAi (Claude Code), versionadas em git para não se perderem
entre sessões. Auto-descobertas via `.claude/skills/`.

## Skills
- **collection-pilot-model** — gera planilhas `.xlsx` de projeção de remuneração para
  pilotos de cobrança (bandas/produtos, 3 cenários, custos, Lucro Presumido, margem,
  modelo híbrido piso+fee, aba Simulador).
- **qa-speech-analytics** — QA & Speech Analytics do voice bot de cobrança (operação HIB
  Principia · OCS Sinergytech): coleta de logs/áudio, parsing determinístico, métricas de
  funil/ASR, controles de rigor estatístico, LGPD e entregáveis. Base de conhecimento
  completa em `references/knowledge-base.md`.
